# romywadhwa.github.io

Personal website for Romy Wadhwa, Senior Manager of Data Analytics.

- `index.html`, `style.css`, `script.js`: the site (no build step, plain HTML/CSS/JS)
- `assets/Romy_Wadhwa_Resume.pdf`: resume download, copied here automatically from the private `romywadhwa/resume` repo

To update the resume, edit it in `romywadhwa/resume`. When its PDF changes there, an action copies it to `assets/` here and pushes. Don't edit the PDF in this repo; it gets overwritten.
